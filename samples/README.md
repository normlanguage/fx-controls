# fx-controls sample ownership

[English](README.md) | [简体中文](README.zh-CN.md)

This module supplies JavaFX control types used by the UI window. The runnable scenario is owned by [ui](https://github.com/normlanguage/ui/tree/main/samples) in its `samples/` directory; use that example to observe the behavior through the public API.

The module identity and pinned dependencies are defined in [module.norm](../fx/controls/module.norm).
